# 04 — 修正官方 WP 回應的視角解讀

Type: task  
Status: resolved

## 現象

v1 原型把 API 回應視為主隊值，三個真實樣本出現負向翻判價值。最小例子為四局上、0 出局空壘、主隊落後 5 分，0–1 翻成 1–0 時客隊差值為 −0.4 個百分點。

## Answer

2026-09-15：回應必須以打方分差／打方勝率解讀。上半局同時反轉分差與取補數後，例子為 +0.2 個百分點，全部 12 個可查表樣本零方向警示；Statcast 主隊基準也提供獨立視角檢查。兩個回歸測試先失敗，再於修正後通過；版本升級 v2 並拒絕舊 v1。決策見 [ADR-0001](../../../docs/adr/0001-savant-probability-perspective.md)。

## Comments

- 2026-09-14 的「官方數值異常」是尚未完成診斷的暫時判斷；最終定位為本地 adapter 的語意轉換錯誤，不應指稱官方模型錯誤。
- 舊 bundle 可沿用，但舊 v1 正規化與報告只能作診斷紀錄，不得繼續用於研究。
