## 背景

原 Train-only 兩機會近似把歷史實際球序的下兩個同隊不利判決當作同價值未來挑戰；剩 2 次額度時 25%／75% 對稱是 `p_f(1-p_f)` 的公式性質，不是已驗證的棒球規律。依使用者討論，介面已保留官方 WP／RE 主輸出、將該代理模型撤離主要門檻；既有程式、結果與報告不刪除。完整理由見[重新設計方案](../../../reports/archive/phase3/phase3_option_value_redesign_plan_2026-10-01.md)。

## 範圍與順序

1. 鎖定 `V(S,c)`、兩行動分支、後續機會的資料定義及第 1–9 局兩次制母體；未驗證來源資格與五場排除另列，不把故障事件當主研究目標。
2. 先對固定 Train／Validation／Test／名義 External 母體審計歷史觀察路徑的下一次同隊不利判決及當時 Game State 的假設翻判 WP 差；不以事後 ABS 正誤或實際挑戰篩選「值得挑戰」的球。後續若擬合到達或狀態模型，只用 Train；Validation 選設定，Test／名義 External 作鎖定評估，按場報不確定性、WP 表外與缺值。
3. 評估是否有足夠行動支持與狀態轉移證據，能讓挑戰／保留兩條路徑分別求值；不得用實際球序複製另一行動、以事後翻判或 `post_action_budget` 作決策時特徵。
4. 若只能採模型假設，先預宣告後續轉移、未來翻判率、合理挑戰選擇及未支援分支的敏感度；再考慮有限視野模擬。資料不足時停在官方 WP／RE 與人工成本情境，不以近似結果冒稱正式 `V(S,c)`。

## 驗收條件

- 產出明確的機會母體、決策時特徵／事後標籤清單、各切分樣本與支持度；Legal 來源未知保持未知。
- 預宣告至少一個可反證的觀察性預測指標與場次層級評估；缺值及表外不可填零或靜默刪除。
- 對零額度後仍有不利判決、跳過低價值球、成功保留／失敗扣額度、兩行動不同後續狀態、九局終局與平手設計測試。
- 在未識別反事實、私有翻判線索與未支援分支前，`formal_counterfactual_option_value_ready=false`、`formal_policy_evaluation_ready=false`；不把情境門檻叫正式 RRA。
