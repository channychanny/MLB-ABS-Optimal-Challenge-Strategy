## 驗收條件

- 保存各年度官方賽程清冊、來源 URL、參數、下載時間、SHA-256 與逐場納入／排除紀錄。
- 下載 Train 與 Validation，按年度／月份／分差／狀態檢查覆蓋；不得把小樣本稱為完整球季。
- Test／External 在設計與資料鎖定前不作選型或調參；開發樣本另列。
- 正式實驗前需本專案可追溯 commit、環境版本及固定 dataset lock；不得重建 Git 或取其他 repository 的 commit 冒充。
- 大比分稀疏區域需呈現場次數與不確定性；超出訓練支持範圍需標示外插風險。
