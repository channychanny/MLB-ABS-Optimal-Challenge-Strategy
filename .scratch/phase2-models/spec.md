# Phase 2 實作規格

## 依據

保留 [產品規格](../../MLB%20ABS%20Optimal%20Challenge%20Strategy%20—%20產品規格書.md) 第 30 節的順序，不將 Future Opportunity 或正式 RRA 提前混入本階段。使用者已同意 Phase 1 ±5 分限定驗收，Phase 2 自建模型需保留超出此範圍的真實分差。

## 第一個交付切片

完整來源小樣本 → 官方投球總數與比分核對 → 第 1–9 局狀態及隔離標籤 → 固定年度 split → Train-only RE24／RE288 與九局平手邊界開發估計。

完整欄位、排除與取樣定義見 [資料契約](../../docs/phase2_dataset.md)。實作不得使用實際 Challenge 列充當一般歷史比賽，也不得用 observed WP／delta 作監督模型特徵或反事實真值。

## 後續交付

先建立正式來源清冊與 commit 基準，再訓練／校準 WP Model A，接回既有 GameState／S0／S1 介面；以官方 ±5 範圍作共同樣本比較，以 6–10／11+ 分組另驗證自建模型。統計不確定性與稀有狀態不能因工程管線成功而省略。

## 非目標

本切片不訓練 WP，不作正式全季估計、不研究延長賽內的挑戰時機、不建立球員翻判預測器，亦不重新初始化既有專案。
