# Savant 原始機率以打方解讀，統一轉成主隊視角

2026-09-15 核對固定快照與獨立查詢後，Game Strategy Explorer 的 `bat_wins_*` 回應必須以「打方分差、打方勝率」解讀；本次 API 的 `perspective=home` 並未完成預期轉換。Adapter 因此在上半局同時反轉分差欄順序並取 `1 − p`，下半局保留原值，再於估值層依固定 Decision Team 決定是否取補數；不沿用網頁標籤推定、也不只轉機率或只轉分差。

## 驗證與後果

- 四局上客隊領先 5 分、0 出局空壘：來源打方 `+5` 欄，0–1 為 0.920、1–0 為 0.922；翻判對客隊增加 0.2 個百分點。錯讀主隊 `−5` 欄會產生 −0.4 個百分點。
- 多個含跑者狀態的轉換後基準更接近 Statcast `home_win_exp`；這只支持視角解讀，不代表兩來源估計窗口、球數處理或校準完全相同。
- 舊 `savant-baseline-v1` 正規化及其衍生報告不再可用，保留作診斷紀錄；從同一原始 bundle 重建 `savant-baseline-v2`。後續下載明確請求 `bat`，離線 adapter 同時接受已保存的 `home` 請求 bundle。
- 不修改官方原始值，不用截零或強制單調性掩蓋錯誤；未來來源變更仍須驗證此契約。
