# ADR-0002：以固定官方 WP 作為主要估值來源

日期：2026-09-21  
狀態：已接受

研究重點是兩次 ABS Challenge 的使用時機，而非重新建立勝率預測器。因此主要研究改用固定版本的官方 Savant WP 與 RE288；自建 WP、全分差模型與全季 Dataset A 擴充移為延伸研究，保留既有成果，不再作 MVP 的前置條件。

## 影響

- 官方值是外部估值假設，不是本專案訓練或校準完成的模型；結論必須附帶來源、覆蓋與外部有效性限制。
- 不將超過 ±5 分的狀態截成 ±5，不把缺值填為零或必勝／必敗。RE288 的狀態表與 WP 分差限制分開處理。
- 當前 S0／S1 可估值不代表所有未來分支可估值。正式 Dynamic Policy 前必須另行鎖定跨出表格範圍的 continuation 設計與敏感度分析；本 ADR 不預先宣稱此問題已解決。
- 九局平手沿用版本化官方邊界；延長賽策略仍不在主要範圍。
- 既有 Dataset A 時間切分保留給延伸研究，不能直接視為官方 WP 的獨立訓練／測試切分。
- 詳細契約見 [官方 WP 主線](../official_wp_policy.md)，新工作順序見 [工作地圖](../../.scratch/official-wp-policy/map.md)。
