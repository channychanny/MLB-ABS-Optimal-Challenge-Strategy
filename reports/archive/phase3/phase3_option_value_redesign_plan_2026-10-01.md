## 已落實的呈現更正

本機介面保留同一份官方快照的 `WP(S0)`／`WP(S1)` 與原半局 `RE(S0)`／`RE(S1)`，將兩者列為主要、可直接核對的狀態估值。RE 是打方本半局的預期得分；守方的有利變化取 `RE(S0)−RE(S1)`，不與 WP 相加。若 WP 任一側表外，仍顯示可估 RE，但不給 WP 門檻。

舊版把 Train-only 兩機會近似的單一成本及 50% 未來翻判率門檻置於首頁主卡片，容易讓人誤認為已識別的最優策略。現行首頁改用既有 `config/phase3_win_decision_protocol.json` 預宣告的**零／較低／較高額度成本假設**。剩 1 次額度時分別為 0／0.5／2.0 個勝率百分點；剩 2 次時為 0／0.25／1.0 個勝率百分點。只顯示每個假設下的條件式持平門檻，以及低至高假設對應的示例範圍；**不是估計值、統計信賴區間或可信上下界**。真正終局後保留額度沒有後續用途，三情境成本皆取 0。使用者另可輸入自己的假設成本。

介面不再依賴受 `.gitignore` 排除的兩機會模型 JSON 才能啟動；舊模型程式、測試、結果及歷史報告均保留，不覆寫或追溯改稱正式實驗。

## 正確的研究量與目前近似的差距

令 `S0` 為維持主審原判後的狀態、`S1` 為成功翻判後的狀態，`c` 為眼前尚有的挑戰次數。若能識別未來政策下的勝率價值 `V(S,c)`，則：

\[
Q_{保留}=V(S0,c),\qquad
Q_{現在挑戰}=(1-p_{現在})V(S0,c-1)+p_{現在}V(S1,c).
\]

失敗少一次額度的真正邊際成本是 `V(S0,c)−V(S0,c−1)`；成功保留額度但比賽狀態改為 `S1`。只有能對上述兩條後續路徑求值，才可把持平翻判率稱為模型內的政策門檻。當分母為正，門檻是 `[V(S0,c)−V(S0,c−1)]/[V(S1,c)−V(S0,c−1)]`。現行介面的 `C/(ΔWP+C)` 只是把官方 `WP(S1)−WP(S0)` 當成成功分支價值差、再插入**人工**成本 `C` 的條件式代數；官方 WP 並非本研究的額度感知 `V`。

舊兩機會模型讀取歷史實際球序的下兩個同隊不利判決，以第一個可估判決的平均正向 WP 差代表兩個未來機會，並假設每次都挑戰、未來翻判率固定。剩 2 次時其成本必然與 `p_f(1−p_f)` 成正比，所以 25%／75% 對稱、50% 最高；這是公式性質，不是觀察到的實戰規律。選擇跳過低價值球、不同機會價值、第三個以後的機會、當前改判對後續 Game State 的影響，都沒有被估計。Train 6,297 個起點中，6,170 個沿歷史球序仍有至少兩個後續同隊不利判決，故「最多兩個」尤其不能冒稱全場視野。第一後續判決有 1,044 個 WP 不支援；只用可估者的均值可能有選擇偏差。這些問題的偏差方向不明，不應自行把近似成本當成上界或下界。

## 資料可支持與不可支持的推論

固定 Dataset B 91 場／13,132 筆有額度暫定候選可描述歷史實際球序；其中 11,060 筆當前雙側 WP 可估、2,072 筆不支援。Train 歷史挑戰只有 155／6,297 筆，預先定義的 12 個局數階段×攻守×額度格僅 2 格達最低雙臂支持。[行動支持稽核](../phase2/dataset_b_action_support_and_censoring_2026-09-29.md)已證明不能直接相減「曾挑戰」與「曾保留」的後續勝率：行動不是隨機的，球員還有資料未記錄的私有誤判線索。零額度後仍出現不利判決，也不能誤當已無潛在機會。ABS 停用／replay 資格未知限制完整 Legal 母體的外推，但不是眼前已可挑戰情境計算 S0／S1 的前置閘門。

因此現有資料可做**下一個歷史機會的預測診斷**，不能單憑 Dataset B 識別「現在改選另一個行動」的因果效果或正式政策增勝。2025 Test 亦不是官方 WP 固定快照的完全獨立測試。翻判成功率 `p_現在` 是球員當時的主觀線索，不是事後 ABS 結果；在沒有可用且校準的決策前線索前，仍只可用情境或呈現條件式門檻。

## 下一版模型的工作順序與停損閘門

| 工作包 | 要做的事 | 驗收前不能說 |
| --- | --- | --- |
| 1. 鎖定 estimand 與機會母體 | 明確區分 Adverse Called Pitch、Legal Challenge Opportunity、Reasonable Candidate；固定第 1–9 局／兩次制／Decision Team，列出來源未知及五場排除的影響。先報所有不利判決與**假設翻判 WP 差**級距的樣本量；此差值可由當時 Game State 求得，不是實際判錯機率，不用事後翻判結果挑出「值得挑戰」球。 | 已取得完整 Legal 母體、可挑戰率或真實誤判率。 |
| 2. 描述未來機會，而非先估政策 | 用 Train 擬合下一同隊不利判決的到達時間、下一 Game State 與當時狀態可計算的假設翻判 `ΔWP` 分布；**每次不利判決都保留，不按實際翻判或 `ΔWP` 正負預篩**。保留零額度潛在判決、九局設限、WP 表外與缺漏。只用決策前特徵，按場分割，在 Validation 選模、Test／名義 External 檢查校準、分層支持、缺值率及遊戲層級不確定性。 | 這條觀察到的路徑就是改選後的反事實路徑。 |
| 3. 明示轉移假設，才建立有限視野模擬 | 對 S0／S1 分別生成後續狀態與機會，不複製同一場的既有未來球序；策略在每個機會可以挑戰或跳過，成功保留、失敗扣額度。對私有翻判把握、未來機會價值、不同政策與未支援分支做情境／區間分析。若採一般逐球資料擴充狀態轉移，需先說明「給定狀態後，後續比賽與判決如何達成該狀態無關」的不可直接驗證假設。 | 從歷史資料識別出真實 `V(S,c)`、最優策略或因果增勝。 |
| 4. 正式政策驗收另設 Gate | 鎖定模型／分母／成本與翻判率假設，檢查 0／1／2 額度單調性、攻守與主客方向、終局、九局平手、跳過低價值球、表外→表內、來源限制。比較永不挑戰、固定門檻與動態模型，按場報不確定性；只把模擬結果稱模型內結果。若支持／校準／表外覆蓋不過關，停在情境範圍。 | 正式 RRA、樣本外政策增勝或「應該挑戰」的無條件建議。 |

優先推薦先執行工作包 1 與 2 的**可行性審計**，而不是立即訓練複雜模型。若審計發現可用狀態支持不足，主研究仍可誠實交付官方 WP／RE 的即時價值與明示成本情境門檻；把反事實額度價值留為延伸。這個停損選項需要在使用 Test／External 看結果之前鎖定。

## 本輪驗證與待討論的研究選擇

實際本機 HTTP 範例（五局下、1 出局、一壘有人、球前 2 壞 1 好、0–0、原判好球、剩 1 次）回傳 `WP(S0)=0.563`、`WP(S1)=0.588`，原半局 `RE(S0)=0.484555`、`RE(S1)=0.707776`。依**人工**低／高成本 0.5／2.0 個勝率百分點，持平門檻為 16.67%／44.44%；不能把區間讀成 95% CI 或真實門檻的可信範圍。WP 表外測例仍回傳 RE，且沒有門檻。全專案 317 項測試、JS 語法及本機 HTTP 端點檢查通過；未完成瀏覽器截圖式視覺驗收。

進入工作包 3 前，需與使用者確定研究最終主張的層級：是以「官方 S0／S1 影響＋明示額度成本情境」作主要可交付結論，並把模型內動態策略列為延伸；還是投入更多資料工程建立**有清楚轉移假設、可樣本外檢查但仍非因果識別**的有限視野模擬。兩者都不應依現有稀疏挑戰行動直接宣稱實證最優政策。建議先完成工作包 1／2，讓支持度結果決定工作包 3 是否值得進行。
