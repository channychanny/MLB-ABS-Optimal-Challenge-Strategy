# 官方 WP 跨界延續：合成有限視野契約驗證

日期：2026-09-24。這是 Phase 2 Issue 03 的**工程驗收原型**，不是從歷史資料估計的 Future Opportunity Model，也不是正式 Dynamic Policy／RRA。第 1–9 局之外沒有挑戰策略；九局平手只使用版本化 regulation boundary。

## 契約

[`continuation_contract.py`](../src/abs_challenge/continuation_contract.py) 接受人工建立的有限分支樹：機率分支、挑戰決策、真實主隊分差路徑，以及終點價值區間。挑戰成功保留額度，失敗扣一；保留行動維持原判。表外中繼狀態可沿明示路徑返回表內，不會被刪除或截為 ±5。若路徑停在表外，終點必須有明示假設的非退化區間；不能悄悄指定固定勝率。已核實的勝負終局可由專用工廠設定 0／1，九局平手使用固定 `savant-regulation-tie-home-v1` 邊界，不展開延長賽。

輸出區分保留與挑戰的勝率區間、曾越界機率質量、越界後回到表內的質量，以及未解終點質量。區間完全分離時才輸出穩健 `challenge`／`save`；重疊則回傳 `undetermined`。當較深的決策仍不確定時，質量用保守上下界而非虛構單一政策。所有機率、未來節點與區間均是**人工合成假設**，不得拿觀測到的後續投球當作挑戰後仍固定的反事實路徑。

## 合成驗收結果

| 情境 | 驗收重點 | 結果 |
| --- | --- | --- |
| 40% 路徑分差 +6 後回到 +5；60% 路徑直接終止 | 回到表內的路徑仍貢獻價值 | 期望值 0.46；越界及回表質量均 0.40 |
| 翻判分支 50% 到 +6，保留分支留表內 | 行動改變越界質量且表外未補值 | 保留越界 0；挑戰越界 0.50、未解 0.50；挑戰價值區間 0.20–0.70，行動 `undetermined` |
| 後面還有一次機會 | 成功保留／失敗扣額度 | 剩 1 次選 `save`，剩 2 次選 `challenge` |
| 表外停點直接指定 0.9 | 禁止靜默固定勝率 | 拒絕；明示假設區間或已核實終局才可繼續 |
| 九局平手與表外已知勝負終局 | 邊界與勝負規則分離 | 平手使用版本化 boundary；已知勝負可給 0／1，但不生成第十局策略 |
| 表外區間敏感度 | 假設可翻轉行動 | 區間 0–1 為 `undetermined`；0.5–0.8 選 `challenge`；0.1–0.3 選 `save`，均只作合成示範 |

驗證命令：`$env:PYTHONPATH='src'; python -m unittest discover -s tests -q`。合成契約測試 6 項，完整測試 231 項通過。

## 尚未跨過的閘門

本模組沒有估計真實機會到達機率、狀態轉移、對手策略或成功率；也沒有把 18 場工程 cohort 的當前缺值當成未來越界機率。即使合成樹能算區間，正式 Phase 3 仍需要來源資格與 Dataset B 時間切分、未見驗證，以及實證的未來分支分布。超界質量過高而行動仍 `undetermined` 時，不能輸出正式 RRA 或全場最適建議。Issue 03 維持 open、`formal_policy_evaluation_ready=false`。
