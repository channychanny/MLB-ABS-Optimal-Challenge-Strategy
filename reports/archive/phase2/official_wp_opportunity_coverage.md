# 官方 WP 覆蓋：固定六場完整逐球驗證

日期：2026-09-22。開發驗證，不是正式全季評估；Issue 01 仍為 claimed。

## 結論

完成前一輪的五球診斷，並補齊固定六場所在三日的完整逐球來源。六場全部通過完整事件對齊、逐球前球數／出局／跑者及比分核對；1–9 局共 1,876 球。沒有依查表結果更換比賽。

| 母體 | 分母 | 兩側支援 | 單側支援 | 兩側超界 | 純判決估值不支援 |
|---|---:|---:|---:|---:|---:|
| 實際挑戰（1–9 局） | 29 | 22 | 0 | 7 | 0 |
| 有額度、投手資格已識別的暫定機會 | 962 | 706 | 3 | 202 | 51 |
| 零額度的不利判決 | 80 | 66 | 0 | 7 | 7 |

實際挑戰是候選母體的子集，不能將三列加總。3 次延長賽挑戰只在 ledger 完整性檢查保留，不進主要母體。

暫定機會查表支援率為 **706／962＝73.39%**。不是 706／全部投球，也不是 MLB 全季的機會覆蓋率。51 次不支援包括 32 次非純 Ball／Called Strike 描述及 19 次額外跑壘事件；仍留在分母，不假造反事實跑壘。

總不利判決 1,042 次，包含 80 次零額度候選，不把零額度誤當「後續沒有機會」。本六場投手角色沒有未知或野手登板候選，但實作會保留 eligibility_unknown、excluded_position_player，不能由小樣本推定全年資格完整。

3 個單側支援案例與 4 個合法 away_win 終局分支另列於 JSON。真實終局可用規則值，不因原比分超界而拒絕；其餘查表缺值不截尾。沒有負向估值警示。

五球皆為終局三振。判決、球數及事件識別一致，沒有額外跑者事件；原因是逐球 count 的出局數延遲更新，而非串接錯球或複合跑壘。

修正只在以下條件全部成立時接受舊出局數：實際結果為第三好球、該打席無後續投球、event.isOut=true、打席結果為 strikeout、打席出局數與預期一致、同一事件有唯一打者三振出局且 outNumber 正確。其他額外跑壘仍經原檢查排除；缺乏打席或跑者證據、出局序號不符均拒絕。不修改 raw feed，也不無條件把 count.outs 加一。

因此前一輪 17／29 更新為 22／29。原 Phase 1 三場仍為 12／16、4 次超界，沒有改變既有缺值結論。

## 可重現性

```powershell
$env:PYTHONPATH = "src"
$env:PYTHONIOENCODING = "utf-8"
python -m abs_challenge.wp_coverage --plan config/official_wp_opportunities.json --output data/processed/wp_opportunities_new.json
python -m unittest discover -s tests -v
```

命令離線執行、拒絕覆寫。exit code 1 表示開發報告已產生、整體研究閘門仍未通過；2 為全域輸入錯誤。單場完整來源／對齊失敗記於 games，不能以其他成功場次掩蓋。

本機驗證輸出：data/processed/wp_opportunities_final_2026-09-22.json 與 wp_opportunities_final_replay_2026-09-22.json。content lock 皆為 `e562eabb5c75eb07a504f3e28069537467252e8b0e739a6cbc1c49294f16a7b3`。各母體另按年度、regime、場次、攻守、局數、真實分差與球數輸出分組報告。

計畫 SHA-256：`ffdaf54ccfa434bb6a73f511fb76faf8264fde8db94cb8579267004afcc6e441`。官方 v2 與規則來源沿用前輪固定版本。來源 manifest 及實體檔 hash 均納入輸入紀錄。舊下載器在 Windows 把 LF 改為 CRLF，因此比對接受原始 bytes 或還原換行後與下載 manifest 完全一致的文字；不是忽略 hash，也不重新標記擷取時間。

執行 HEAD 為 `f9883721bcc9d62fcc999e6f36f5e8488e972b6c`、工作目錄不乾淨，新增程式未提交；runtime 保存程式檔 hash，不宣稱這是該 commit 的正式實驗。raw／processed 仍排除於 Git，新 clone 需另取得相同快照。

**214 項測試通過**。新增涵蓋終局三振的必要證據、額外跑壘仍拒絕、未挑戰球、零額度、資格未知／野手、完整投球缺漏、比分錯誤、零挑戰場次仍處理母體及 Windows manifest／內容變動拒絕。
